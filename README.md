# Nudge

Landing page and launch collateral for **Nudge** — workflow automation for local and regional service businesses (HVAC, plumbing, property management, and similar trades).

## Contents

- `nudge-landing.html` — the live landing page (self-contained, published as a Claude artifact)
- `nudge-landing-v1-kraft-backup.html` — earlier kraft-paper design, kept as a reference/fallback
- `onepager.html` — source for the one-pager PDF
- `build.js` — generates `AI_Consulting_Launch_Plan.docx`
- `build_audit.js` — generates `Nudge_Workflow_Audit_Template.docx`
- `logo-assets/` — wordmark and icon PNGs, plus base64-encoded copies used to embed the logo directly into HTML
- Delivered files: `Nudge_OnePager.pdf`, `AI_Consulting_Launch_Plan.docx`/`.pdf`, `Nudge_Workflow_Audit_Template.docx`/`.pdf`
